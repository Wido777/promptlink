How the attack works

Most AI assistants accept a prompt inside the link itself. Opening the link runs the prompt as if you had typed it. Microsoft's security team found 50+ such prompts from 31 companies and named the technique AI Recommendation Poisoning.

  1. A site adds a "Summarize with AI" button.Its link carries a prompt: a summary request plus a line about the site's brand.
  2. You click it.Your assistant opens and runs the whole prompt, including the part you never saw.
  3. Memory keeps the extra line.Weeks later you ask for a recommendation, and the brand comes up as if the assistant had judged it on its own.

If a link is flagged

  • Don't open it. If you still want the summary, paste the article's address into a new chat yourself.
  • If you already clicked one, open your assistant's memory or personalization settings and delete anything you didn't add.
  • Found one on a real site? Report it on GitHub so the rules can improve.
