How it works

One click, a lasting bias

AI assistants can take a prompt from the link itself, and opening the link runs it as if you'd typed it. Microsoft found 50+ such prompts from 31 companies using this to plant their brand in people's AI memory. They call it AI Recommendation Poisoning.

  1. A site adds a "Summarize with AI" buttonIts link carries a summary request plus one line about the site's brand.
  2. You click itYour AI runs the whole prompt, including the line you never saw.
  3. Your AI remembers itWeeks later it recommends that brand as if it had chosen it on its own.

Command line

Check links in bulk

The same rules as a Python tool with no dependencies. Check a list of links, or scan a saved page or email for every AI button in it.

pip install git+https://github.com/Wido777/promptlink
promptlink check "https://chatgpt.com/?q=..."
promptlink page saved_page.html
