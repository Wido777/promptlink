The attack

One click, a lasting bias

Most AI assistants accept a prompt inside the link itself, and opening the link runs it as if you typed it. Microsoft's security team found 50+ of these prompts from 31 companies and named it AI Recommendation Poisoning.

  1. A site adds a "Summarize with AI" buttonThe link carries a summary request plus one line about the site's brand.
  2. You click itYour assistant opens and runs the whole prompt, including the line you never saw.
  3. Memory keeps that lineWeeks later you ask for a recommendation, and the brand comes up as if the assistant chose it.

What to do

If a link is flagged

  • Don't open it. If you still want the summary, paste the article's address into a new chat yourself.
  • Already clicked one? Open your assistant's memory or personalization settings and delete anything you didn't add.
  • Found one on a real site? Report it on GitHub so the rules get better.
